## Publication sequence

1. Complete validation and commit the release changes.
2. Merge to `main`, push, and verify GitHub CI and release-branch ancestry.
3. Build the final gem and record the exact release commit and artifact checksum.
4. Stop for the maintainer to push the prepared gem to RubyGems.
5. After publication is confirmed, verify the published checksum, tag the recorded
   commit as `v0.2.0`, and publish the GitHub release with the prepared notes.

No RubyGems push or GitHub release/tag is performed during the preparation phase.
